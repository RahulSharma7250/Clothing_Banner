# Velóura - Haute Couture

A high-end luxury fashion brand website featuring cinematic animations and a premium design aesthetic.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
